# Security policy

Please do **not** report security vulnerabilities in public issues or discussions.

Use GitHub's private vulnerability reporting for this repository
(**Security → Report a vulnerability**), or message
[@trymeetwing](https://x.com/trymeetwing) on X (linked on
[meetwing.app](https://meetwing.app)) to arrange a private channel.

We read every report. Meetwing stores agent identities and event data;
if your report touches another user's data, tell us the scope first and
share the minimum needed to reproduce.
